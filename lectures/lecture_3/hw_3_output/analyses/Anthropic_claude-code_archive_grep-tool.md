- **Путь:** Anthropic/claude-code/archive/grep-tool.md
- **Вендор:** Anthropic
- **Продукт:** grep-tool
- **Объём:** 4125 символов

## Структура
1. **HTML-комментарий (metadata)** — служебная заметка о версии Claude Code, статусе инструмента (не входит в основной набор main-agent, но доступен саб-агентам) и дате верификации.
2. **Заголовок и краткое описание** — объявление инструмента: «Content search built on ripgrep», с указанием преимущества перед Bash-альтернативами (интеграция с permission UI и file links).
3. **Ключевые особенности** — перечисление возможностей: regex, фильтры glob/type, output_mode, multiline.
4. **JSON Schema (параметры инструмента)** — полная спецификация всех параметров с типами, описаниями, enum, required и additionalProperties: false.

## Persona
Persona как таковая отсутствует. Файл не задаёт роль ассистента, а описывает техническую спецификацию одного инструмента (Grep) в экосистеме Claude Code. Тон сугубо технический, документационный — без характерных черт, эмоций или поведенческих рамок.

## Сильные стороны
- **Эталонная спецификация инструмента.** JSON Schema с detailed descriptions, enum-значениями, conditional requirements (например, -A/-B/-C работают только при output_mode: "content") — образец для описания tool-интерфейсов.
- **Умные умолчания.** head_limit по умолчанию 250 — защита от перегрузки контекста без жёсткого запрета.

## Слабые места
- **Отсутствие persona и guardrails.** Файл описывает только технический интерфейс, но не задаёт, как ассистент должен выбирать этот инструмент, в каких случаях его применять, а в каких — нет.
- **Нет few-shot примеров.** Пользователю (или ассистенту) не показано, как выглядит корректный вызов и ожидаемый результат.
- **Нет chain-of-thought.** Не требуется обдумывать выбор параметров перед вызовом.

## Что заимствовать
- **JSON Schema с conditional requirements.** Указание, что параметры -A/-B/-C/-n/-o игнорируются вне режима content — отличный приём для описания условной валидации параметров инструмента.
- **Механизм head_limit с умолчанием.** Задание разумного лимита (250) с возможностью отключения (0) — баланс между безопасностью контекста и гибкостью.
