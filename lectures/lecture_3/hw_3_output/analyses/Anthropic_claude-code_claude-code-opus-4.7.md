# Анализ: Anthropic / Claude Code Opus 4.7

## Метаданные
- **Путь:** Anthropic/claude-code/claude-code-opus-4.7.md
- **Вендор:** Anthropic
- **Продукт:** claude-code-opus-4.7
- **Объём:** ~170 565 байт (один из крупнейших известных системных промптов)

## Структура
1. **Role definition** — объявление ассистента как Claude Code, официального CLI Anthropic для работы с кодом
2. **Security guardrails** — правила допустимого и недопустимого использования (security testing, запрет destructive техник)
3. **URL restrictions** — запрет на генерацию/угадывание URL без уверенности
4. **System rules** — общие правила: вывод текста, permission mode, обработка system-reminder, hooks, контекстное сжатие
5. **Doing tasks** — инструкции по выполнению software engineering задач: стиль кода, безопасность, комментарии, рефакторинг
6. **Executing actions with care** — оценка обратимости и blast radius действий, примеры рискованных операций
7. **Using your tools** — предпочтения по выбору инструментов, параллельные вызовы, TaskCreate
8. **Tone and style** — стиль общения: без эмодзи, кратко, ссылки на код с file_path:line_number
9. **Text output** — правила текстового вывода для пользователя, формат обновлений
10. **Session-specific guidance** — специфические инструкции для сессии (shell команды, Agent tool, навыки)
11. **Auto memory** — система персистентной файловой памяти с типами (user, feedback, project, reference)
12. **Environment** — информация об окружении (ОС, shell, модель, директория)
13. **Scratchpad Directory** — указание директории для временных файлов
14. **Context management** — управление контекстом при длинных разговорах
15. **Session context** — git status, CLAUDE.md, email пользователя, текущая дата
16. **Agents** — описание доступных типов агентов (claude, Explore, Plan и др.)
17. **Skills** — описание доступных навыков (deep-research, dataviz, code-review и др.)
18. **Tools** — полная документация всех инструментов с JSON-схемами (Bash, Read, Write, Edit, Agent, Artifact и др.)

## Persona
Ассистент объявлен как **Claude Code** — официальный CLI-инструмент Anthropic для работы с программным кодом. Тон — деловой, технический, безэмоциональный. Рамки заданы строго: это интерактивный агент для software engineering, а не универсальный ассистент. Persona подчёркивается через стиль общения (кратко, без эмодзи, без нарратива внутренних размышлений) и через фокус на инженерные задачи.

**Итоговая оценка:** 3.7 / 5

## Сильные стороны
- **Исключительно детальная проработка guardrails** —多层次的安全限制: от общих запретов до конкретных примеров рискованных операций с чёткими критериями, когда нужно спрашивать разрешение у пользователя.
- **Глубокая интеграция с инструментами** — каждый инструмент документирован с полной JSON-схемой, примерами использования и правилами выбора.
- **Система персистентной памяти (auto memory)** — проработанная система сохранения контекста между сессиями с типами памяти, правилами сохранения и примерами.
- **Иерархия агентов и навыков** — чёткое разделение на специализированные под-агенты (Explore, Plan, code-review) и навыки (skills) с триггерами активации.

## Слабые места
- **Отсутствие few-shot примеров** — нет ни одного образца диалога «пользователь → ассистент», что могло бы улучшить качество ответов в специфических сценариях.
- **Слабая Chain-of-Thought** — нет формального требования рассуждать пошагово перед ответом, что важно для сложных инженерных задач.
- **Чрезмерный объём** — 170KB промпта создаёт риск потери ключевых инструкций в «шумах» для модели; часть содержимого (полные JSON-схемы инструментов) дублирует встроенные знания модели.

## Что заимствовать
- **Многоуровневая система guardrails** с конкретными примерами рискованных операций и чёткими критериями, когда нужно подтверждение пользователя — отличный шаблон для любого промпта, работающего с инструментами.
- **Система персистентной памяти** с типами (user/feedback/project/reference), правилами сохранения и примерами — лучшая реализация memory-системы среди известных системных промптов.
- **Формат документирования инструментов** — каждый инструмент описан с назначением, when-to-use/when-not-to-use, примерами и JSON-схемой параметров.
